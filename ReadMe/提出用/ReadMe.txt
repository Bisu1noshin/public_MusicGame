ゲーム名:BeatBlast

操作方法（ゲームパッド使用）
　曲選択
　　左スティック:カーソル移動
　　A:決定
　　B:戻る
　ゲーム中
　　左スティック:左レーンのノーツ
　　右スティック:右レーンのノーツ
　　フリックノーツ:矢印の向きにタイミングよく倒す
　　ホールドノーツ:矢印の向きに倒し続ける
　　ラッシュノーツ:スティックを回転させる
　リザルト
　　マウスでボタンを押すとタイトルに戻る

担当箇所
　オ：タイトル画面、ゲームアイコン
　大西：リザルト画面、譜面制作
　亀田：曲選択画面、譜面制作補助ツール
　神田：メインゲーム部分作成

PRポイント
　ゲーム外で専用の譜面制作補助ツールを作成し、効率的な譜面制作が可能になっている。

ソースコード引用
　https://raspberly.hateblo.jp/entry/UnityTextScroller
　　リザルトや曲選択で、長いタイトルの文字をスクロールさせる目的で使用。

各提出バージョンに関しての定義
　α:一人でプレイができる状態　スコア計算、判定が問題なく、譜面も1曲分はできている								
　β:二人プレイができる状態　対戦して、勝敗がつく
　完成:完成版　演出やUI
