ゲーム名:BeatBlast

ゲームのルール
　フリックノーツ:矢印の向きにタイミングよく倒す
　ホールドノーツ:矢印の向きに倒し続ける
　スコアは(Perfectの個数)*2+(Greatの個数)
　70%以上のスコアを獲得でクリア
　Miss0でフルコンボ、GreatとMissどちらも0でオールパーフェクト

操作方法（ゲームパッド使用）
　モード・曲選択
　　左スティック:カーソル移動
　　A:決定
　　B:戻る
　ゲーム中
　　左スティック:左レーンのノーツ
　　右スティック:右レーンのノーツ
　リザルト
　　任意のボタンを押すとタイトルへ戻る

操作方法（キーボード使用）
　モード・曲選択
　　WASD:カーソル移動
　　Space:決定
　ゲーム中
　　WASD:左レーンのノーツ
　　↑←↓→:右レーンのノーツ
　リザルト
　　任意のキーを押すとタイトルへ戻る

担当箇所
　オ：タイトル画面、ゲームアイコン、デザイン面
　大西：リザルト画面、譜面制作
　亀田：モード・曲選択画面、譜面制作補助ツール
　神田：メインゲーム部分作成

PRポイント
　ゲーム外で専用の譜面制作補助ツールを作成し、効率的な譜面制作が可能になっている。

ソースコード引用
　https://raspberly.hateblo.jp/entry/UnityTextScroller
　　リザルトや曲選択で、長いタイトルの文字をスクロールさせる目的で使用。

各提出バージョンに関しての定義
　α:一人でプレイができる状態　スコア計算、判定が問題なく、譜面も1曲分はできている								
　β:二人プレイができる状態　対戦して、勝敗がつく
　完成:完成版　演出やUI
